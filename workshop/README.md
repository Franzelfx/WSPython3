# Python3 Workshop Learning Path

## How to use this path

Three tracks, 15 stations each. Work left to right.
Each station is one `.py` file: der Docstring oben enthält Erklärung und Übung,
darunter steht das Code-Beispiel.

| Track | Farbe | Inhalt |
|-------|-------|--------|
| [Track 1 — Python Basics](01_Python_Basics/) | Peach | Foundations: syntax, data types, control flow, functions |
| [Track 2 — Intermediate](02_Intermediate_Python/) | Lavender | Functional tools, errors, I/O, decorators, generators |
| [Track 3 — Advanced](03_Advanced_Python/) | Sage | OOP, inheritance, magic methods, modules, packages |

Ausführen einer Station:

```bash
python3 workshop/01_Python_Basics/01_variablen_datentypen.py
```
